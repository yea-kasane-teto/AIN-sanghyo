01
01 · NEURAL NETWORKS

신경망은 무엇을 배우는 걸까요?

딥러닝은 여러 층의 신경망으로 데이터의 표현을 학습하는 머신러닝의 한 방법이에요.

이미지를 분류한다면 입력은 픽셀의 숫자이고, 출력은 각 범주에 대한 점수예요. 그 사이의 은닉층은 입력을 새로운 숫자 묶음, 즉 표현(representation)으로 바꿔요. 여러 층이 이 변환을 반복하면서 다음 층이 활용할 특징을 만들어요. 이미지에서는 선이나 질감, 부분의 조합 같은 표현이 나타날 수 있지만, 각 뉴런에 사람이 정한 의미가 반드시 하나씩 대응하는 것은 아니에요.

한 뉴런은 가중합과 활성화를 계산해요

가중치 w는 입력을 얼마나, 어떤 부호로 반영할지 정해요. 편향 b는 입력과 별개로 더하는 값이에요. 이렇게 만든 가중합 z를 활성화 함수 f에 넣으면 뉴런의 출력 a가 나와요. 학습은 이 계산 규칙을 유지하면서 w와 b를 데이터에 맞춰 바꾸는 과정이에요.

z = w₁x₁ + w₂x₂ + … + b   →   a = f(z)

x: 입력 · w: 가중치 · b: 편향 · z: 활성화 전 값 · a: 뉴런의 출력

숫자로 따라가기 · 뉴런 하나

입력 x₁ = 0.7, x₂ = 0.3이고, 가중치가 0.7, −0.5, 편향이 0.05라면

z = 0.7 × 0.7 − 0.5 × 0.3 + 0.05 = 0.39
a = ReLU(0.39) = 0.39

음수 가중치는 해당 입력의 기여를 빼요. 편향은 활성화가 시작되는 위치를 옮길 수 있어요.

깊이와 너비는 서로 달라요

깊이는 변환을 연속으로 몇 번 거치는지, 너비는 한 층에서 몇 개의 출력을 만드는지와 관련돼요. 층이 많으면 표현을 단계적으로 조합할 수 있지만, 더 깊거나 넓다고 항상 더 잘 학습하는 것은 아니에요. 계산량, 데이터의 양, 최적화와 과적합도 함께 고려해야 해요.

완전연결층에서 입력이 m개, 출력 뉴런이 n개라면 가중치는 m × n개, 편향은 n개예요. 이처럼 학습으로 바뀌는 수를 파라미터(parameter)라고 불러요. 입력층은 값을 전달하며, 보통 자체 가중치나 편향을 갖지 않아요.

연결 수와 파라미터 수 구분하기

3 → 4 → 4 → 4 → 2 구조의 가중치는 3×4 + 4×4 + 4×4 + 4×2 = 52개예요. 편향 4+4+4+2 = 14개를 더하면 학습할 파라미터는 66개예요.

개념 확인층과 너비에 따라 연결이 얼마나 늘어날까요?＋

관찰할 것 은닉층 수를 고정하고 너비를 늘려 보세요. 뉴런 수와 연결 수가 같은 비율로 늘어나는지 비교해요.

02 · ACTIVATION

층 사이에 비선형성이 필요한 이유

활성화 함수는 단순히 값을 줄이는 장치가 아니라, 신경망의 표현력을 만드는 요소예요.

활성화 없이 가중합만 두 번 계산해 볼게요. 첫 층이 h = W₁x + b₁이고 다음 층이 y = W₂h + b₂라면, 합쳐서 y = (W₂W₁)x + (W₂b₁ + b₂)가 돼요. 결국 한 번의 가중합과 편향으로 표현할 수 있어요. 층 사이에 비선형 함수를 넣으면 이런 단순한 합치기가 일반적으로 불가능해지고, 입력에 따라 다른 패턴을 표현할 수 있어요.

대표 활성화 함수의 역할과 한계
함수계산과 출력 범위어디에 쓰고 무엇을 주의할까요?
ReLUmax(0, z) · 0 이상은닉층에서 널리 쓰여요. z > 0에서는 기울기가 1이지만, 음수 구간에서는 0이어서 일부 뉴런이 학습되지 않을 수 있어요.
Sigmoid1 / (1 + e−z) · 0과 1 사이이진 분류의 출력에 활용해요. |z|가 크면 출력이 포화되고 기울기가 작아져요.
Tanhtanh(z) · −1과 1 사이양수와 음수를 모두 출력해요. 0 주변과 달리 양끝에서는 포화돼요. 출력 평균이 자동으로 0이 되는 것은 아니에요.

음수 입력과 포화 비교하기

z = −2일 때 ReLU는 0, Sigmoid는 약 0.119, Tanh는 약 −0.964예요. z = 5에서 6으로 바꾸면 ReLU는 1만큼 변하지만 Sigmoid는 약 0.0042만 변해요. 출력이 거의 변하지 않는 구간에서는 미분값도 작아져요. 이 성질이 뒤에서 기울기 소실과 연결돼요.

은닉층과 출력층의 선택은 달라요

은닉층에서는 표현과 기울기 흐름을, 출력층에서는 문제에 맞는 결과 형식을 고려해요. 제한 없는 실숫값을 예측하는 회귀에서는 출력층에 활성화를 생략할 수 있어요. 이진 분류에서는 Sigmoid, 서로 배타적인 여러 범주 중 하나를 고르는 분류에서는 Softmax로 여러 점수를 합이 1인 값으로 바꿀 수 있어요. 여러 정답이 동시에 가능한 다중 라벨 문제는 범주별 Sigmoid를 사용할 수 있어요.

Sigmoid를 통과했다고 그 값이 곧 실제 정답 확률을 정확히 나타내는 것은 아니에요. 데이터, 학습 상태, 확률 보정에 따라 해석이 달라져요.

03 · FORWARD PASS

순전파는 현재 파라미터로 예측하는 과정이에요

입력에서 출력 방향으로 각 층의 계산을 차례대로 수행해요.

여러 뉴런의 가중치를 행렬 W에 모으면 한 층의 계산을 짧게 쓸 수 있어요. 이전 층의 출력 a를 다음 층의 입력으로 쓰고, 마지막 층까지 같은 절차를 반복해요. 여기서 l은 층 번호이고 a⁽⁰⁾는 원래 입력 x예요.

z⁽ˡ⁾ = W⁽ˡ⁾a⁽ˡ⁻¹⁾ + b⁽ˡ⁾
a⁽ˡ⁾ = f⁽ˡ⁾(z⁽ˡ⁾)

한 행의 가중치가 뉴런 하나에 해당해요. 마지막 출력은 예측값 ŷ로 표시해요.

입력 2개 → 은닉 뉴런 3개 → 출력 1개

입력은 (0.7, 0.3)이고 은닉층에는 ReLU를 써요. 각 뉴런의 계산은 다음과 같아요.

  1. z₁ = 0.7×0.7 − 0.5×0.3 + 0.05 = 0.39
  2. z₂ = 0.3×0.7 + 0.8×0.3 − 0.1 = 0.35
  3. z₃ = −0.6×0.7 + 0.2×0.3 + 0.2 = −0.16

ReLU를 통과하면 은닉층 출력은 (0.39, 0.35, 0)이 돼요. 출력층의 가중치를 (0.9, −0.65, 0.4), 편향을 −0.1로 두면

s = 0.9×0.39 − 0.65×0.35 + 0.4×0 − 0.1 = 0.0235
ŷ = Sigmoid(s) ≈ 0.5059

이 숫자는 임의로 정한 파라미터의 계산 결과예요. 아직 실제 데이터를 학습한 예측은 아니에요.

순전파만으로는 가중치가 바뀌지 않아요

학습에서는 순전파 결과와 정답으로 손실을 구하고, 역전파와 업데이트를 이어서 수행해요. 추론(inference)에서는 학습한 파라미터로 새 입력의 결과를 계산해요. 보통 정답이나 역전파가 필요하지 않아요. Dropout처럼 학습과 추론에서 동작이 달라지는 층도 있어서 실행 모드를 올바르게 선택해야 해요.

관찰할 것 ReLU와 기본 입력 (0.7, 0.3)에서 본문의 계산을 확인한 뒤 특징 A만 바꿔 보세요.

04 · LOSS FUNCTION

손실 함수는 예측을 어떻게 평가할까요?

학습이 무엇을 줄여야 하는지 정하는 기준이 손실 함수예요.

정답 y와 예측 ŷ가 주어지면 손실 L은 그 예측이 목표에서 얼마나 벗어났는지를 수치로 나타내요. 파라미터를 θ로 묶어 쓰면 예측은 ŷ = fθ(x)예요. 학습할 때는 보통 여러 샘플의 손실을 평균 낸 목적 함수 J(θ)를 줄여요. 정규화 항을 더하면 J에는 그 항도 포함돼요.

J(θ) = (1/B) Σᵢ L(fθ(xᵢ), yᵢ)

B: 이번 계산에 사용하는 배치의 샘플 수. 합은 배치의 모든 샘플에 대해 계산해요.
문제와 출력 형식에 맞는 손실
문제대표 손실해석
연속값 회귀제곱 오차 (ŷ − y)²
평균하면 MSE		차이를 제곱해 큰 오차에 더 큰 값을 부여해요. 단위와 이상치에 영향을 받아요.
이진 분류BCE = −[y ln p + (1−y) ln(1−p)]y는 0 또는 1, p는 1에 대한 예측값이에요. 틀린 답을 확신할수록 손실이 커져요.
단일 정답 다중 분류교차 엔트로피 = −ln p정답Softmax가 만든 분포에서 정답 범주에 배정한 값이 작을수록 손실이 커져요.

정확도가 같아도 손실은 다를 수 있어요

정답이 1인 샘플에서 p = 0.8이면 BCE는 −ln(0.8) ≈ 0.223, p = 0.4이면 약 0.916이에요. p = 0.6과 p = 0.9는 둘 다 기준 0.5를 넘어서 정답으로 분류되지만, 손실은 약 0.511과 0.105로 달라요.

정확도는 맞힌 비율을 보여 주고, 손실은 예측값이 움직일 방향을 미분으로 계산할 수 있게 해요. 둘을 함께 관찰하되 같은 지표로 생각하지 않아요.

이 페이지의 역전파 예시는 미분 과정을 읽기 쉽도록 L = ½(ŷ − y)²를 사용해요. ½는 미분할 때 계수 2를 없애는 상수예요. 이진 분류 실무에서는 BCE를 흔히 사용하며, 로그와 Sigmoid를 안정적으로 함께 계산하는 구현을 활용해요. 예를 들어 BCEWithLogitsLoss에는 Sigmoid를 적용하기 전 점수인 로짓(logit)을 전달해요.

05 · GRADIENT DESCENT

경사하강법은 파라미터를 어떻게 바꿀까요?

손실의 기울기를 구한 뒤, 손실이 줄어드는 방향으로 조금씩 이동해요.

가중치 w의 미분값 ∂J/∂w는 다른 파라미터를 고정한 채 w를 아주 조금 늘릴 때 손실이 얼마나 변하는지 알려 줘요. 양수이면 w를 줄이는 쪽, 음수이면 늘리는 쪽이 국소적으로 손실을 낮추는 방향이에요. 모든 파라미터의 편미분을 모은 벡터가 기울기 ∇θJ예요.

θ새 값 = θ현재 값 − η ∇θJ

η(에타): 학습률. 가중치뿐 아니라 학습하는 편향도 각자의 기울기로 업데이트해요.

한 번의 업데이트를 직접 계산해요

모양을 쉽게 보기 위해 파라미터 하나의 함수 J(w) = ½(w − 1)²를 생각해요. 최솟값의 위치는 w = 1이고, 미분은 dJ/dw = w − 1이에요.

현재 w = 3 → 기울기 = 2 → 현재 손실 = 2
η = 0.2 → 새 w = 3 − 0.2 × 2 = 2.6
새 손실 = ½(2.6 − 1)² = 1.28

다음 단계에서는 이동한 위치 w = 2.6에서 기울기를 다시 계산해요. 같은 기울기 2를 계속 빼는 것이 아니에요.

학습률은 한 번에 움직이는 크기를 정해요

학습률이 너무 작으면 개선이 느리고, 너무 크면 좋은 위치를 지나쳐 진동하거나 손실이 커질 수 있어요. 위 함수에서는 η = 1이면 한 번에 w = 1에 도착하지만, 이는 이 함수의 특별한 성질이에요. 딥러닝 전체에 통하는 최적 학습률은 없어요. 학습 중 학습률을 줄이는 스케줄을 사용하기도 해요.

신경망의 손실 지형에는 많은 파라미터, 평평한 구간, 안장점 등이 있어요. 기울기는 현재 위치 근처의 정보를 주므로 한 번의 이동이나 전체 학습이 항상 손실을 줄이거나 전역 최솟값에 도달한다고 보장할 수 없어요. 미니배치의 구성이 바뀌어도 관측 손실은 흔들릴 수 있어요.

개념 확인학습률이 너무 크면 어떻게 될까요?＋

관찰할 것 η = 0.2로 3회 이동한 뒤 η = 2.2로 바꿔 같은 횟수만큼 이동해 보세요. w가 1에 가까워지는지와 손실이 줄어드는지를 함께 읽어요.

같은 출발점에서 학습률 비교하기

함수 J(w) = ½(w − 1)², 시작 w = 3. 학습률을 바꾸면 같은 시작점으로 초기화돼요.

    06 · BACKPROPAGATION

    역전파는 각 파라미터의 기울기를 계산해요

    역전파로 기울기를 구하고, 경사하강법 같은 최적화 방법으로 파라미터를 업데이트해요.

    앞쪽 가중치 하나를 바꾸면 은닉층, 출력층, 손실이 연쇄적으로 변해요. 이 경로를 따라 미분을 곱하는 연쇄법칙(chain rule)이 필요해요. 역전파는 순전파에서 계산한 중간값을 활용하고, 손실에서 입력 방향으로 미분을 전달해 많은 파라미터의 기울기를 효율적으로 구하는 방법이에요.

    ∂L/∂w = (∂L/∂ŷ) × (∂ŷ/∂z) × (∂z/∂w)

    단일 뉴런 z = wx + b, ŷ = Sigmoid(z)의 예예요. 여러 경로가 합쳐지는 지점에서는 각 경로의 미분 기여를 더해요.

    연쇄법칙을 숫자 세 개로 연결하기

    앞의 3개 은닉 뉴런 예시와 별개로, 뉴런 하나만 생각해요. x = 2, w = 0.5, b = 0, y = 1이면 z = 1, ŷ ≈ 0.7311이에요. 손실은 L = ½(ŷ − y)²예요.

    ∂L/∂ŷ = ŷ − y ≈ −0.2689
    ∂ŷ/∂z = ŷ(1 − ŷ) ≈ 0.1966
    ∂z/∂w = x = 2
    ∂L/∂w ≈ −0.2689 × 0.1966 × 2 ≈ −0.1058

    여기까지가 기울기 계산이에요. 학습률 η = 0.1로 w만 업데이트하고 b는 고정하면 새 w ≈ 0.5106이 돼요. 미분이 음수이므로 w가 늘고, 같은 입력의 출력이 목표 1 쪽으로 이동해요.

    기울기의 크기는 현재 상태에서의 민감도예요. 어떤 뉴런이 얼마나 “잘못했는지”를 배분하는 점수가 아니에요. 또한 역전파 자체에는 학습률을 적용하는 업데이트가 포함되지 않아요. 아래 버튼은 역전파와 경사하강법 두 작업을 순서대로 실행해요.

    08 · GRADIENT FLOW

    깊은 신경망에서 기울기를 안정적으로 전달해요

    기울기 소실(vanishing gradient)은 앞쪽 층까지 전달되는 미분값이 매우 작아져 업데이트가 거의 이루어지지 않는 현상이에요. 반대로 기울기 폭발(exploding gradient)은 미분값이 과도하게 커져 업데이트가 불안정해지는 현상이에요. 순전파의 출력이 작다는 말과 역전파의 기울기가 작다는 말은 구분해야 해요.

    실제 신경망에서는 가중치 행렬과 여러 경로의 합까지 관여해요. 이 단일 경로 예시는 원리를 보여 주기 위한 단순화예요.

    Sigmoid와 Tanh는 포화 구간에서 미분이 작아요. ReLU는 양수 구간의 미분이 1이어서 이 문제를 완화할 수 있지만, 음수 구간은 0이고 가중치의 영향도 남아 있어요. ReLU를 선택하는 것만으로 기울기 소실이나 폭발이 모두 해결되지는 않아요.

    09 · GENERALIZATION

    학습한 데이터 밖에서도 잘 작동해야 해요

    훈련 손실을 낮추는 것과 새로운 데이터에서 잘 예측하는 것은 서로 다른 목표예요.

    학습 데이터에만 지나치게 맞춰 새로운 데이터에서 성능이 떨어지는 현상을 과적합(overfitting)이라고 해요. 훈련 손실이 계속 내려가는데 검증 손실이 올라가기 시작한다면 과적합의 신호일 수 있어요. 훈련 데이터로 파라미터를 학습하고, 검증 데이터로 설정과 중단 시점을 선택한 뒤, 테스트 데이터로 최종 성능을 평가해요.

    Dropout은 학습 중 일부 출력을 무작위로 0으로 만들어요

    매 학습 단계에서 각 뉴런의 출력을 확률 p로 끄고, 나머지 연결로도 결과를 만들도록 해요. 특정 특징의 조합에만 의존하는 것을 줄이는 데 도움을 줄 수 있어요. 파라미터를 영구히 삭제하는 방법은 아니며, 모든 구조에서 반드시 성능을 높이는 것도 아니에요.

    학습: ã = m × a / (1 − p),   m ∈ {0, 1}
    추론: ã = a

    각 m은 1일 확률이 1−p인 무작위 마스크예요. 여기서는 널리 사용하는 inverted dropout 방식을 설명해요.

    p = 0.5일 때 출력 2는 어떻게 될까요?

    학습 중에는 절반의 확률로 0, 나머지 절반의 확률로 2/(1−0.5) = 4가 돼요. 평균적으로는 원래 값 2를 유지해요. 추론할 때는 Dropout을 끄므로 그대로 2를 전달해요. 뉴런이 10개라고 매번 정확히 5개만 꺼지는 것은 아니에요.

    Dropout은 일반화를 돕는 정규화 기법이에요. 앞 단원의 기울기 소실을 직접 해결하는 방법으로 분류하지 않아요. 아래 그림에서는 은닉층 두 곳에만 적용하지만, 실제 적용 위치와 확률은 모델 구조에 따라 달라져요.

    설명과 연결하기 이 그림은 마스크만 보여 줘요. 살아남은 출력의 1/(1−p) 배율은 안내문에 표시하며, 실제 모델의 성능 향상이나 훈련 결과를 계산하지는 않아요.

    Dropout 외에도 여러 방법을 함께 살펴봐요

    • 가중치 감쇠(weight decay): 큰 가중치를 억제하도록 업데이트에 감쇠를 적용해요. 일반 SGD에서는 L2 벌점과 대응하지만, Adam 같은 적응적 방법에서는 둘을 구분해야 해요.
    • 조기 종료(early stopping): 검증 성능이 개선되지 않을 때 학습을 멈추고 좋은 검증 성능을 보인 상태를 선택해요.
    • 데이터 증강: 정답의 의미를 유지하는 범위에서 학습 입력을 변형해 다양한 경우를 보게 해요. 예를 들어 이미지의 가벼운 이동은 도움이 될 수 있지만, 숫자 6을 뒤집는 변환은 정답을 바꿀 수 있어요.

    전체 흐름을 말로 설명해 보세요

    신경망이 입력을 표현으로 바꾸고 → 순전파가 예측을 만들고 → 손실 함수가 목표와의 차이를 수치로 나타내고 → 역전파가 기울기를 계산하고 → 최적화 방법이 파라미터를 바꿔요. 이 과정을 배치마다 반복하면서 검증 데이터로 일반화 성능을 확인해요.
