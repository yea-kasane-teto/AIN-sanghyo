01
01 · LAYERS

층을 쌓아 신경망의 표현을 만들어요

각 층은 앞 층에서 받은 신호를 새 표현으로 바꿔 다음 층에 전달해요. 여러 층을 거치며 간단한 표현을 조합해 더 복잡한 특징을 나타낼 수 있어요.

신경망 구조 바꾸기

전체 은닉 뉴런12개
층 사이 연결64개

입력층 → 은닉층 → 출력층

구조 보기

은닉층 3개와 층별 뉴런 4개로 구성된 신경망이에요.

입력층

이미지나 문장처럼 모델이 살펴볼 자료를 받아요.

은닉층

앞 층의 신호를 조합해 다음 단계에 쓸 표현을 만들어요.

출력층

층을 모두 지난 신호를 결과로 내보내요.

02
02 · ACTIVATION

활성화가 층마다 다른 표현을 가능하게 해요

뉴런은 받은 신호를 활성화 함수에 통과시켜 다음 층에 보낼 값을 만들어요. 비선형 활성화가 있어야 층을 쌓았을 때 단순한 변환을 넘어 더 복잡한 관계를 표현할 수 있어요.

뉴런의 활성화 바꾸기

ReLU 출력1.00

음수 신호는 0으로, 양수 신호는 그대로 전달해요.

입력 신호에 따른 뉴런 출력

활성화 곡선

점이 현재 입력 위치예요. 함수를 바꾸고 입력 신호를 움직여 보세요.

03 · FORWARD PASS

순전파로 입력이 결과가 돼요

입력층의 값은 은닉층을 차례로 통과하고, 각 뉴런에서 변환된 뒤 출력층까지 이동해요. 아래 예시는 작은 신경망을 통과하는 신호를 실시간으로 보여줘요.

입력 신호 조절하기

마지막 층의 출력—입력을 바꾸면 신호가 다시 계산돼요.

층을 지나가는 신호

입력 → 은닉 → 출력

읽는 법: 노드 안의 숫자는 해당 층에서 만들어진 출력값이에요. 밝은 선은 다음 뉴런에 신호를 전달하는 연결을 나타내요. 이 예시는 원리를 보기 위한 작은 고정 신경망이에요.

04
04 · BACKPROPAGATION

역전파는 결과의 오차를 거꾸로 전달해요

출력과 목표가 다르면, 역전파는 그 차이를 만든 연결을 출력층에서 앞쪽 층으로 거슬러 살펴봐요. 각 가중치가 결과에 끼친 영향을 계산해 신경망의 어느 부분을 어떻게 고칠지 알려줘요.

작은 신경망 한 번 고치기

출력층에서 앞쪽 층으로

가중치 수정 0회

버튼을 눌러 오차가 연결을 따라 거꾸로 전달되는 모습을 살펴보세요.

핵심: 역전파는 층마다 따로 추측해 고치는 대신, 최종 오차에서 시작해 각 연결의 몫을 계산해요. 아래 그림에서 강조된 선은 이번 수정에서 더 큰 영향을 받은 연결이에요.
05
05 · DEEP NETWORKS

층이 깊어질수록 학습 신호를 잘 지켜야 해요

오차를 뒤로 전달할 때 층마다 신호가 약해지면 앞쪽 층이 충분히 배우지 못할 수 있어요. 이를 기울기 소실이라고 불러요. 활성화 함수의 선택과 일부 뉴런을 잠시 쉬게 하는 Dropout은 깊은 신경망의 학습을 돕는 대표 아이디어예요.

Dropout은 학습할 때 일부 은닉 뉴런을 무작위로 쉬게 해요. 한 뉴런에만 지나치게 기대지 않도록 돕고, 입력층과 출력층은 계속 작동해요.

신경망의 구조와 신호 흐름을 모두 살펴봤다면 학습 완료로 표시할 수 있어요.
