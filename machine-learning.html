01 · CONCEPT

머신러닝이란?

컴퓨터가 데이터에서 패턴을 학습하고, 학습한 패턴을 이용해 새로운 데이터의 결과를 예측하는 방법이에요.

데이터

공부 시간과 실제 시험점수를 모아요.

패턴

시간과 점수 사이의 관계를 직선으로 찾아요.

예측

새로운 공부 시간을 넣어 예상 점수를 구해요.

02 · HOW IT WORKS

예측하고, 비교하고, 조금씩 수정해요

입력값 x는 공부 시간, 정답 y는 실제 점수예요. 선형회귀 모델은 예상 점수 = 가중치 w × 공부 시간 + 편향 b로 계산해요.

① 데이터 입력② 모델이 예측③ 정답과 비교 · 손실 계산④ 가중치와 편향 수정 ↻

손실은 예측 오차를 제곱한 값의 평균(MSE)이에요. 경사하강법은 이 손실이 작아지는 방향으로 w와 b를 반복해서 조정해요. 아래에서 실제 숫자로 확인해 보세요.
