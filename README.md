# AIN — 필수 수학

AIN 학습 로드맵의 **필수 수학** 영역을 위한 독립형 정적 페이지입니다. 벡터 내적과 경사하강법을 직접 바꿔보며 벡터·행렬·텐서·미분·확률의 기초를 익힙니다.

## 로컬에서 열기

저장소 루트에서 정적 웹 서버를 실행한 뒤 `index.html`을 열면 됩니다. 별도 빌드나 패키지 설치는 필요하지 않습니다.

## 파일

- `index.html`: 학습 페이지의 구조와 콘텐츠
- `styles.css`: AIN 메인 페이지의 색상과 카드 스타일을 따른 반응형 레이아웃
- `app.js`: 벡터 내적과 경사하강법 인터랙션

## 공개 주소

GitHub Pages를 저장소의 `main` 브랜치 루트에서 제공하면 `https://yea-kasane-teto.github.io/AIN-sanghyo/`에서 열 수 있습니다. AIN 메인 페이지의 수학 카드도 이 주소로 연결하도록 설정합니다.
