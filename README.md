# AIN — 필수 수학

AIN 학습 로드맵의 **필수 수학** 영역을 위한 독립형 정적 페이지입니다. 벡터 내적과 경사하강법을 직접 바꿔보며 벡터·행렬·텐서·미분·확률의 기초를 익힙니다.

## 로컬에서 열기

저장소 루트에서 정적 웹 서버를 실행한 뒤 `index.html`을 열면 됩니다. 별도 빌드나 패키지 설치는 필요하지 않습니다.

## 파일

- `index.html`: 학습 페이지의 구조와 콘텐츠
- `styles.css`: AIN 메인 페이지의 색상과 카드 스타일을 따른 반응형 레이아웃
- `app.js`: 벡터 내적과 경사하강법 인터랙션

## 공개 및 메인 레포 연결

1. GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
2. 브랜치는 `main`, 폴더는 `/(root)`로 저장합니다.
3. 배포 주소는 `https://yea-kasane-teto.github.io/AIN-sanghyo/`입니다.

AIN 메인 페이지의 필수 수학 카드는 이 주소를 열도록 [초안 PR](https://github.com/yea-kasane-teto/AIN-main/pull/1)에 연결 변경을 올렸습니다. Pages를 켜고 PR을 병합하면 메인 카드에서 이 페이지로 이동합니다.
